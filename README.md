Calculadora de Índice de Masa Corporal 
(IMC)Una aplicación web sencilla e intuitiva para calcular el Índice de Masa Corporal (IMC) a partir del peso y la altura ingresados por el usuario. Ofrece una clasificación clara sobre la composición corporal basada en los rangos estándares de salud.🚀 CaracterísticasCálculo instantáneo: Obtén tu IMC de forma rápida al ingresar tu peso (kg) y tu altura (m o cm).Interpretación del resultado: Muestra la categoría correspondiente según los parámetros de la Organización Mundial de la Salud (OMS):Bajo peso ($IMC < 18.5$)Peso normal ($18.5 \le IMC < 25.0$)Sobrepeso ($25.0 \le IMC < 30.0$)Obesidad ($IMC \ge 30.0$)Interfaz sencilla y amigable: Diseño limpio pensado para facilitar la usabilidad desde cualquier dispositivo.
 Tecnologías Utilizadas

HTML5: Estructura de la aplicación.

CSS3: Estilos y diseño responsivo.

JavaScript: Lógica de cálculo del IMC y manipulación del DOM.

Clona este repositorio:

git clone https://github.com/agustin-silva2026/calculadora-imc.git


Accede al directorio del proyecto:

cd calculadora-imc


Abre el proyecto:
Abre el archivo index.html en tu navegador web preferido.
